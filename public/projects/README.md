# Project screenshots

Replace the placeholder WebP files in these folders with real screenshots of your own work.

Recommended sizes:

- `lucent/cover.webp` — 1600×900; `cover-800.webp` — 800×450
- `lucent/gallery-1.webp` … `gallery-3.webp` — 1200×800; matching `-800.webp` — 800×533
- `memento/cover.webp` — 1600×900; `cover-800.webp` — 800×450
- `memento/gallery-1.webp` … `gallery-2.webp` — 1200×800; matching `-800.webp` — 800×533
- `java-treasure-game/cover.webp` — 1600×900; `cover-800.webp` — 800×450

The site shows a clean gradient fallback if a file is missing. After adding real images, update the `alt` text (and optionally `status: 'ready'`) in `src/data/projects.ts`.

Do not use stock photos or AI-generated fake screenshots.
